# For A Child — Preschool & Daycare Website

Modern, accessible Next.js website scaffold for a premium preschool/daycare brand.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Semantic HTML, SEO metadata, JSON-LD

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content workflow

All placeholder copy, contact details, and navigation live in:

- `src/content/site.ts`

Replace placeholders as real branding, photos, and copy are provided. Do not invent school-specific details.

Brand colors are CSS variables in `src/app/globals.css` (`--brand`, `--accent`, etc.) for easy swapping.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint
